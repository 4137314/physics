#+title: Pseudo-NMOS logic
#+summary: A single PMOS with grounded gate (always on, saturated when the output is low) pulls up an NMOS network: only \(N+1\) transistors for an \(N\)-input gate, but ratioed — \(V_{OL}\) is set by \(\frac{K_p}{2}(V_{DD}-|V_{TP}|)^2=K_{n,eq}\left(V_{DD}-V_{TN}-\frac{V_{OL}}2\right)V_{OL}\) — and it burns static power whenever the output is low.

* Method
1. Pull-up current with output low (PMOS saturated): \(I=\frac{K'_p}{2}\left(\frac WL\right)_p(V_{DD}-|V_{TP}|)^2\).
2. Replace the worst-case conducting pull-down path by an equivalent transistor: \(n\) in series of \((W/L)\) → \((W/L)/n\); in parallel → sum.
3. Impose \(V_{OL}\) (e.g. \(\le V_{TN}\) of the next gate) in the triode equation and solve for \((W/L)_{eq}\) or for the maximum \(n\).
4. Static power \(V_{DD}I\) times the fraction of time the output is low.

* Worked example (exam July 2024)
\(n\)-input NAND, \(V_{TN}=-V_{TP}=0.5\) V, \(V_{DD}=1.8\) V, \(K'_n=280\), \(K'_p=120\) µA/V², \((W/L)_p=1/4\), each NMOS \(1/1\). Pull-up: \(I=\frac{120}{2}\cdot\frac14(1.3)^2=25.35\) µA. Equivalent pull-down at \(V_{OL}=0.5\) V: \((W/L)_{eq}=\frac{25.35}{280(1.8-0.5-0.25)\cdot0.5}=0.172=\frac{1}{5.8}\). With \(n\) series devices of \(1/1\): \((W/L)_{eq}=1/n\ge1/5.8\Rightarrow n\le5\).

* Comparison with static CMOS
| aspect       | static CMOS       | pseudo-NMOS                   |
|--------------+-------------------+-------------------------------|
| transistors  | 2N                | N + 1                         |
| V_OL         | 0                 | > 0 (ratioed)                 |
| static power | ≈ 0 (leakage)     | V_DD·I when output low        |
| fan-in speed | slow for wide NOR | fast wide NOR (parallel NMOS) |

* Engineering applications
Wide NOR decoders and PLAs, address comparators, places where area matters more than standby power.

* Pitfall
Pseudo-NMOS NAND is the *worst* choice for large fan-in (series pull-down fights a constant pull-up); NOR is where it shines.
