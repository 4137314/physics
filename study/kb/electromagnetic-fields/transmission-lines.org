#+title: Transmission lines
#+summary: Distributed \(R,L,G,C\) per metre give the telegrapher equations with waves \(V^\pm e^{\mp\gamma z}\), \(Z_0=\sqrt{\frac{R+j\omega L}{G+j\omega C}}\); a load reflects \(\Gamma_L=\frac{Z_L-Z_0}{Z_L+Z_0}\) and a lossless line of length \(\ell\) transforms it into \(Z_{in}=Z_0\frac{Z_L+jZ_0\tan\beta\ell}{Z_0+jZ_L\tan\beta\ell}\).

* Derivation
KVL and KCL on a section \(\dd z\): \(-\partial_zv=Ri+L\partial_ti\), \(-\partial_zi=Gv+C\partial_tv\). Phasors: \(\frac{\dd^2V}{\dd z^2}=\gamma^2V\), \(\gamma=\sqrt{(R+j\omega L)(G+j\omega C)}\). Solution
\[ V(z)=V_0^+e^{-\gamma z}+V_0^-e^{\gamma z},\qquad I(z)=\frac{V_0^+e^{-\gamma z}-V_0^-e^{\gamma z}}{Z_0}. \]
At the load (\(z=0\)): \(V_0^-/V_0^+=\Gamma_L\). At distance \(\ell\) from the load the impedance formula above follows by dividing \(V\) by \(I\).

* Key results (lossless)
| quantity        | formula                                 |
|-----------------+-----------------------------------------|
| phase velocity  | 1/√(LC) = c/√ε_eff                      |
| VSWR            | (1 + ⎮Γ⎮)/(1 − ⎮Γ⎮)                     |
| return loss     | −20 log⎮Γ⎮ dB                           |
| short, length ℓ | Z_in = jZ₀ tan βℓ (inductive if βℓ<π/2) |
| open, length ℓ  | Z_in = −jZ₀ cot βℓ                      |
| quarter-wave    | Z_in = Z₀²/Z_L                          |
| half-wave       | Z_in = Z_L                              |
Power to the load \(P=\frac{|V_0^+|^2}{2Z_0}(1-|\Gamma|^2)\).

* Transients
A step \(V_s\) through \(R_s\) launches \(V^+=V_s\frac{Z_0}{R_s+Z_0}\); it bounces with \(\Gamma_L\) and \(\Gamma_s\) (bounce diagram), converging to the DC value. Time-domain reflectometry reads \(\Gamma(t)\) to locate discontinuities at \(d=v\,t/2\).

* Worked example
\(Z_0=50\) Ω, \(Z_L=100+j50\) Ω: \(\Gamma_L=\frac{50+j50}{150+j50}=0.447\angle26.6^\circ\), VSWR \(=2.62\), return loss 7 dB, 20% of the power reflected. A quarter-wave transformer for a 100 Ω resistive load needs \(Z_1=\sqrt{50\cdot100}=70.7\) Ω.

* Engineering applications
PCB traces and connectors (signal integrity: ringing, reflections when rise time \(<2\times\) delay), coax and twisted pair, on-chip interconnect at multi-GHz, RF matching networks, TDR cable fault location, the lumped-element limit of [[id:circuits][circuit theory]] (\(\ell\ll\lambda\)).

* Pitfall
Lumped circuit analysis fails when line length exceeds roughly \(\lambda/10\) or the edge travel distance: a 10 cm FR-4 trace (\(v\approx c/2\)) has 0.67 ns delay, longer than a 100 ps edge.
