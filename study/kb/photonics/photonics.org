#+title: Integrated photonics: the map of the subject
#+summary: Silicon-on-insulator (Si core \(n\approx3.48\), SiO\(_2\) cladding \(n\approx1.44\)) confines light in sub-micron waveguides; from them one builds couplers, interferometers, rings, Bragg gratings, grating couplers, carrier-based modulators and Ge detectors — photonic integrated circuits fabricated in CMOS foundries.

* Overview
| block      | notes                                                      |
|------------+------------------------------------------------------------|
| waveguides | effective index method, strip/rib waveguides, group index  |
| passive    | directional couplers, MZI, ring resonators, Bragg gratings |
| I/O        | grating couplers (and edge couplers)                       |
| active     | silicon modulators, Ge photodetectors                      |
| structures | photonic crystals                                          |

* Design flow
Mode solver (FDE) → propagation (FDTD/EME) → compact models (S-parameters, [[id:scattering-parameters][same formalism as microwaves]]) → circuit simulation → layout (GDS) → fabrication tolerance analysis (±10 nm width changes \(n_{eff}\) noticeably).

* Engineering applications
Datacenter transceivers (400G/800G), coherent transceivers, LiDAR (optical phased arrays), biosensors (ring resonance shift), quantum photonic chips, optical interconnects for AI accelerators.
